# Cours Service

Microservice `cours` developpe avec Node.js, Express et PostgreSQL.

## Démarrage local

```bash
npm install
npm start
```

Variables principales :

- `PORT=8080`
- `DATABASE_URL=postgres://postgres:postgres@localhost:5432/coursdb`
- `RABBITMQ_URL=amqp://guest:guest@localhost:5672`
- `EUREKA_HOST=localhost`
- `EUREKA_PORT=8761`
